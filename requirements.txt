# Additive: the legacy Flask stack is unaffected by these being present.
# Retired together with requirements.txt itself when PLAN_FASTAPI.md section 9
# moves the project to pyproject.toml.
#
# BOUNDED, unlike the rest of this file. Every other line here floats, and that
# is a real exposure the migration did not create and does not fix - but these
# five are where an unannounced upgrade breaks the PORT specifically: FastAPI is
# still 0.x, Starlette's response internals are used directly (Range handling,
# the JSON encoder), and pydantic 1 -> 2 is the precedent for how bad a major
# can be. The upper bounds exclude the next major; they are not a lockfile.
# PLAN_FASTAPI.md section 9 moves this file to pyproject.toml, which is where
# the whole dependency set should get pinned properly.
fastapi>=0.115,<1.0
uvicorn[standard]>=0.30,<1.0
pydantic-settings>=2.0,<3.0

# time, not at request time.
python-multipart>=0.0.9,<1.0
# Imported directly by archihub/api/resources/validation.py for ISO date
